# Uber Rides Analytics Dashboard | Python & Power BI

## Project Overview
End-to-end analytics project on Uber rides data (2024).
Data cleaned in Python and visualized in Power BI.

## Tools Used
Python · Pandas · Power BI · DAX · Data Visualization

## Dashboard Pages
1. Executive Overview
2. Cancellation Analysis
3. Time & Customer Experience
4. Peak Booking Timing Analysis
5. Revenue Analysis

## What I Did
- Data cleaning in Python — null values, data type corrections
- Built 5-page interactive Power BI dashboard
- Used KPI cards, slicers, and page navigators
